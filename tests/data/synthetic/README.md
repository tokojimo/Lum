# Fixtures synthétiques publiques

Ce répertoire est le seul emplacement prévu pour une fixture de régression
historique versionnée. Ne jamais y copier un classeur réel non anonymisé.

Le paquet attendu, sa procédure d'anonymisation, ses schémas, ses tolérances et
ses critères d'acceptation sont définis dans
[`docs/historical_validation.md`](../../../docs/historical_validation.md).

Le fichier `.gitkeep` demeure tant qu'aucun paquet complet et vérifiable n'a
été fourni. Son absence signifie que l'équivalence avec l'ancien pipeline ne
peut pas être revendiquée ; elle ne doit pas être remplacée par une fixture
fabriquée à partir du nouveau moteur.
